# Content notes

Code in this repo is MIT licensed (see LICENSE). The map content has
its own rules:

- **Node descriptions** are original summaries written for this project,
  licensed CC BY-SA 4.0. Scoring anchors (takedown 2, sweep 2, knee on
  belly 2, guard pass 3, mount/back 4) are facts derived from the IBJJF
  rulebook, phrased in our own words.
- **Videos are third-party YouTube content.** They are linked and embedded,
  never rehosted. Creators retain all rights; if you own a video and want
  it removed or credited differently, open an issue.
- **Scope is no-gi.** Gi-only positions and grips are out of scope for now.
- **No analytics, no tracking.** The static site sets no cookies; YouTube
  embeds load only when you press play, via youtube-nocookie.
- **Node IDs are stable.** Once published, a node ID never renames —
  renames become aliases, so bookmarks don't break.
